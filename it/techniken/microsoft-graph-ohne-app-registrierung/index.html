    Chiamare Microsoft Graph senza registrazione dell'app

    Domanda del quiz

    Perché una chiamata Graph può fallire con 403 nonostante il ruolo di amministratore?

    Soluzione

    1. A) Nel token manca l'autorizzazione necessariaEsatto. Le autorizzazioni nel token limitano l'accesso. Un ruolo di amministratore non le estende.
    2. B) Le chat non si possono leggere tramite GraphSbagliato. Graph offre le chat. Manca solo l'autorizzazione giusta nel token di questo connettore.
    3. C) L'URL risorsa di base è impostato in modo erratoSbagliato. Anche un URL di base errato può causare problemi, ma non spiega un'autorizzazione mancante nel token.

    Di cosa si tratta

    Per Microsoft Graph di solito registri un'app in Microsoft Entra ID e gestisci segreti o certificati. L'azione «Richiama una richiesta HTTP» del connettore «HTTP con Microsoft Entra ID (preautorizzato)» si occupa di ottenere il token. Accedi e imposti URL risorsa di base e URI risorsa su https://graph.microsoft.com. Poi scegli metodo ed endpoint, per esempio GET su /v1.0/me. L'accesso dipende dalle autorizzazioni del token. Possibili destinazioni sono, a seconda del connettore, per esempio Microsoft Graph o SharePoint. Controlla i servizi e le autorizzazioni supportati dal tuo connettore. Un ruolo di amministratore non estende le autorizzazioni del token. Le altre pagine di una risposta Graph le ottieni tramite @odata.nextLink.

    L'espressione dal tip

    https://graph.microsoft.com

    Quando usarla, quando no

    Usala

    Per richieste a nome della persona connessa, se il connettore ha le autorizzazioni necessarie.

    Meglio di no

    Quando al connettore mancano le autorizzazioni necessarie o a te i diritti d'uso adeguati per Premium.

    Errore più frequente

    Scambiare un 403 per una richiesta sbagliata. Se nel token manca l'autorizzazione, nessun'altra scrittura aiuta.
