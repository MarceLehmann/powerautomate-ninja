    Mit Static Result testen, ohne Daten zu ändern

    Quizfrage

    Was bewirkt Static Result bei einer Aktion?

    Auflösung

    1. A) Sie läuft, ihre Ausgabe wird aber nicht gespeichertFalsch. Mit Static Result läuft die Aktion gar nicht. Genau deshalb ändert sie keine Daten.
    2. B) Sie läuft nur, wenn du den Flow manuell startestFalsch. Static Result hängt nicht von der Art des Starts ab. Es gilt bei jedem Lauf, solange es eingeschaltet ist.
    3. C) Sie liefert eine feste Ausgabe, ohne zu laufenRichtig. Die Aktion gilt als erfolgreich und gibt das vorgegebene Ergebnis weiter, ohne wirklich zu laufen.

    Worum es geht

    Manche Aktionen willst du beim Testen nicht wirklich ausführen: Sie verschicken Mails, ändern Datensätze oder dauern lange. Mit Static Result gibst du einer Aktion ein festes Ergebnis vor. Im Designer schaltest du dafür im Bereich Testing der Aktion «Enable Static Result» ein und legst fest, welche Ausgabe sie liefern soll. Beim nächsten Lauf gilt die Aktion als erfolgreich, ohne dass sie ausgeführt wird. Die folgenden Schritte arbeiten mit deiner vorgegebenen Ausgabe weiter. So testest du die Logik danach in Ruhe und mit verschiedenen Fällen, ohne echte Daten anzufassen. Vor dem Einsatz im Betrieb schaltest du das statische Ergebnis wieder aus.

    Wann einsetzen, wann nicht

    Einsetzen

    Für Aktionen, die Mails senden, Daten ändern oder lange dauern, während du die Schritte danach testest.

    Lieber nicht

    Im Betrieb. Bleibt Static Result eingeschaltet, führt der Flow die Aktion nie wirklich aus.

    Häufigster Fehler

    Static Result nach dem Testen eingeschaltet lassen. Der Flow meldet Erfolg, obwohl die Aktion nie gelaufen ist.

    Lizenz

    Standard Läuft ohne Premium-Connector, also mit der Lizenz aus Microsoft 365. Beleg bei Microsoft Learn: Power Automate licensing FAQ. Für deinen ganzen Flow: Lizenz-Check.
