    Filter array im Advanced Mode

    Quizfrage

    Wann wechselst du bei Filter array in den Advanced Mode?

    Auflösung

    1. A) Wenn mehrere Bedingungen in einen Filter gehörenRichtig. Im Advanced Mode schreibst du die Bedingung als Ausdruck und verknüpfst mehrere Prüfungen mit and() oder or().
    2. B) Wenn du die Einträge nach einem Feld sortieren willstFalsch. Filter array lässt Einträge weg, sortiert aber nicht. Die Reihenfolge bleibt gleich.
    3. C) Wenn der Filter direkt in SharePoint laufen sollFalsch. Filter array arbeitet im Flow auf einem Array, das schon geladen ist, nicht in der Datenquelle.

    Worum es geht

    Die Aktion Filter array bietet im einfachen Modus eine Bedingung mit Feld, Operator und Wert. Für viele Fälle reicht das nicht: zwei Bedingungen gleichzeitig, eine Oder-Verknüpfung oder ein Vergleich mit einem berechneten Wert. Statt mehrere Filter hintereinander zu schalten, wechselst du in den Advanced Mode. Dort schreibst du die Bedingung als Ausdruck und kombinierst Funktionen wie equals(), contains(), and() und or(). Auch dynamische Inhalte aus früheren Aktionen kannst du einbeziehen. So bleibt es bei einer einzigen Aktion, und der Flow wird übersichtlicher. Einfache Vergleiche zeigt der Designer weiterhin als Felder an.

    Wann einsetzen, wann nicht

    Einsetzen

    Wenn du mehrere Bedingungen kombinieren oder mit berechneten Werten vergleichen willst.

    Lieber nicht

    Wenn ein einziger Vergleich reicht. Dann bleibt der einfache Modus lesbarer.

    Häufigster Fehler

    Mehrere Filter array hintereinander schalten, obwohl ein Ausdruck mit and() dasselbe in einem Schritt erledigt.

    Lizenz

    Standard Läuft ohne Premium-Connector, also mit der Lizenz aus Microsoft 365. Beleg bei Microsoft Learn: Power Automate licensing FAQ. Für deinen ganzen Flow: Lizenz-Check.
