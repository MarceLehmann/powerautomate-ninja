    Feste Werte in Compose statt in Variablen

    Quizfrage

    Wohin gehört eine Mailadresse, die sich im Flow nie ändert?

    Auflösung

    1. A) In eine Variable, damit der Flow schneller läuftFalsch. Eine Variable macht den Flow nicht schneller. In Schleifen verhindert sie sogar, dass Apply to each parallel läuft.
    2. B) In eine Compose-Aktion oder in Parse JSONRichtig. Feste Werte brauchen keine Variable. Compose oder Parse JSON zeigen klar, dass sich der Wert nicht ändert.
    3. C) In eine eigene Condition am Anfang des FlowsFalsch. Eine Condition prüft etwas und verzweigt. Zum Ablegen eines festen Werts ist sie nicht da.

    Worum es geht

    Viele Flows beginnen mit einer Reihe von «Initialize variable» für Werte, die sich nie ändern: eine Mailadresse, eine Listen-URL, ein Schwellenwert. Für feste Werte brauchst du keine Variable. Ein einzelner Wert gehört in eine Compose-Aktion. Mehrere zusammengehörige Werte legst du als JSON-Objekt in Parse JSON ab und greifst mit einem Ausdruck wie outputs('Parse_JSON')?['settingName'] darauf zu. Der Flow wird kürzer, und alle sehen sofort, dass diese Werte fest sind. Dazu kommt ein Grund aus der Praxis: Setzt du eine Variable in einer Schleife, läuft Apply to each nur noch nacheinander. Variablen behältst du für Werte, die sich während des Laufs wirklich ändern, etwa eine laufende Summe.

    Der Ausdruck aus dem Tipp

    outputs('Parse_JSON')?['settingName']

    Wann einsetzen, wann nicht

    Einsetzen

    Für Einstellungen, die während des Laufs gleich bleiben: Adressen, URLs, Schwellenwerte, Texte.

    Lieber nicht

    Für Werte, die sich im Lauf ändern, etwa eine Summe oder ein Array, das du Schritt für Schritt füllst. Dafür sind Variablen da.

    Häufigster Fehler

    Im Schema von Parse JSON Felder als Pflicht markieren, die manchmal fehlen. Dann scheitert der Lauf an der Schemaprüfung.

    Lizenz

    Standard Läuft ohne Premium-Connector, also mit der Lizenz aus Microsoft 365. Beleg bei Microsoft Learn: Power Automate licensing FAQ. Für deinen ganzen Flow: Lizenz-Check.
