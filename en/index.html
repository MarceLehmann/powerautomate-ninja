    The belt path

    Seven belts, from the first test to architecture

    1. White belt: Operating4 techniques, 11 questions

      You test flows, read the inputs and outputs of every action and format dates directly.

    2. Yellow belt: Expressions7 techniques, 26 questions

      You write your first expressions, filter and clean up arrays and test loops with just a few items.

    3. Orange belt: Control5 techniques, 21 questions

      You catch errors with scopes, control concurrent runs and return data to Power Apps.

    The threshold. From green on it gets technical: messy data, parallel loops, calls to SharePoint and Microsoft Graph.

    1. Green belt: Hardening6 techniques, 24 questions

      You process messy data safely, speed up loops and call SharePoint and Microsoft Graph directly.

    2. Blue belt: Reading errors1 technique, 17 questions

      You read the real error message from a scope and pass it on to people or agents.

    3. Brown belt: Architecture1 technique, 6 questions

      You keep processes alive for weeks, even beyond the run duration limit of a flow.

    4. Black belt: Master examGoal

      Flows as tools for agents: routers and calls that correct themselves.
