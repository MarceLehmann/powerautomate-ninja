    Is my license enough?

    Four questions about your flow. The verdict tells you whether the license from Microsoft 365 is enough or what you need Power Automate Premium for.

    Answer the four questions and the verdict appears here.
      1. Which data sources does your flow work with?

      SharePoint, Office 365 Outlook, Microsoft Teams and Excel Online (Business) are standard connectors.

      2. Do you need a custom connector or "HTTP with Microsoft Entra ID"?
      3. Does your flow read or write data in Dataverse?
      4. Should your cloud flow start a desktop flow on a machine?

      What the verdict is based on

      • With a license from Microsoft 365 you use standard connectors. If a flow uses no premium connector, you do not need a premium license.
      • Microsoft Dataverse and HTTP with Microsoft Entra ID are premium connectors. Custom connectors and desktop flows started from cloud flows are not included in the license from Microsoft 365.
      • If an automated or scheduled flow with a premium connector runs, only the owner needs the premium license. For flows that people start with a button, every person who starts it needs one.
      • This assumes your Microsoft 365 subscription includes Power Automate. The Licensing FAQ lists which plans do.

      Sources, as of 2026-10-16: Power Automate licensing FAQ, Deep dive on specific licenses, List of all Standard tier connectors, List of all Premium tier connectors, Microsoft Dataverse connector reference, HTTP with Microsoft Entra ID (preauthorized) connector reference. No licensing advice for individual cases: for contracts, ask your Microsoft partner.
