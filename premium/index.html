    Lizenz-Check, Stand 16.10.2026

    Reicht meine Lizenz?

    Vier Fragen zu deinem Flow. Das Urteil sagt dir, ob die Lizenz aus Microsoft 365 reicht oder wofür du Power Automate Premium brauchst.

    Beantworte die vier Fragen, das Urteil erscheint hier.
      1. Mit welchen Datenquellen arbeitet dein Flow?

      SharePoint, Office 365 Outlook, Microsoft Teams und Excel Online (Business) sind Standard-Connectoren.

      2. Brauchst du einen Custom Connector oder «HTTP with Microsoft Entra ID»?
      3. Liest oder schreibt dein Flow Daten in Dataverse?
      4. Soll dein Cloud Flow einen Desktop Flow auf einem Rechner starten?

      Worauf das Urteil beruht

      • Mit einer Lizenz aus Microsoft 365 nutzt du Standard-Connectoren. Verwendet ein Flow keinen Premium-Connector, brauchst du keine Premium-Lizenz.
      • Microsoft Dataverse und HTTP with Microsoft Entra ID sind Premium-Connectoren. Custom Connectors und Desktop Flows aus Cloud Flows sind in der Lizenz aus Microsoft 365 nicht enthalten.
      • Startet ein automatisierter oder geplanter Flow mit Premium-Connector, braucht nur der Besitzer die Premium-Lizenz. Bei Flows, die Personen per Knopf starten, braucht sie jede Person, die startet.
      • Voraussetzung ist, dass dein Abo aus Microsoft 365 Power Automate enthält. Welche Pläne das sind, steht in der Licensing FAQ.

      Quellen, Stand 16.10.2026: Power Automate licensing FAQ, Deep dive on specific licenses, List of all Standard tier connectors, List of all Premium tier connectors, Microsoft Dataverse, Connector-Referenz, HTTP with Microsoft Entra ID (preauthorized), Connector-Referenz. Keine Lizenzberatung im Einzelfall: Für Verträge fragst du deinen Microsoft-Partner.

      Diese Techniken laufen mit Standard

      • Datum direkt in utcNow() formatieren
      • Flow testen, bevor er live geht
      • Aktionen über My clipboard wiederverwenden
      • Mit Code View hinter eine Aktion schauen
      • Filter array im Advanced Mode
      • Feste Werte in Compose statt in Variablen
      • Duplikate mit union() entfernen
      • Mit Static Result testen, ohne Daten zu ändern
      • Sicherer Zugriff mit dem Operator ?
      • Schleifen beim Testen mit take() kürzen
      • float() vor div() für korrekte Dezimalstellen
      • Fehler mit Try, Catch und Finally abfangen
      • Flow-Läufe nacheinander statt gleichzeitig
      • Timeout für lange Aktionen festlegen
      • Apostrophe und Sonderzeichen richtig codieren
      • Flow-Daten als JSON an Power Apps zurückgeben
      • Apply to each parallel laufen lassen
      • JSON-Objekt statt Switch
      • JSON-Schema, das null verträgt
      • Entscheidungen über ein geteiltes Postfach
      • SharePoint-Datei per REST umbenennen
      • Die echte Fehlermeldung mit result() auslesen
      • Approvals über 30 Tage am Leben halten
